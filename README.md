## 🤖 Overview

JoyFusion combines reference images and text prompts to create unique fused visuals, letting artists blend styles, characters, and scenes with AI assistance.

Whether you're a newcomer or a veteran, JoyFusion provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Image Blending** | Merge two or more reference images into a coherent new artwork |
| **Style Transfer** | Apply the visual style of one image to the content of another |
| **Face Consistency** | Maintains character face identity across generated variations |
| **Prompt Mixing** | Blend multiple text prompts with adjustable influence weights |
